SQLGuard is a security platform that provides AI‑agent permission controls for production data operations. It introduces an Authorization Receipt mechanism where AI agents must request and receive explicit permission before performing write actions. The service offers a gateway API that evaluates policies, scopes actions, and returns time‑bound authorizations, helping organizations enforce data protection and compliance for AI‑driven workflows.

**Areas:** Company · Security · AI · Authorization · Data-Protection · API-Management
